Diseño y Modelado de Escenario 3D

Creación integral de entorno orientado a videojuegos usando Blender

Para este proyecto, el objetivo principal fue diseñar un escenario optimizado para su integración en motores de juego. El proceso abarcó desde el modelado *blockout* inicial hasta el texturizado y la configuración de una iluminación atmosférica adecuada para guiar la experiencia del jugador.

Optimización y Texturizado

Se prestó especial atención a la topología de las mallas para mantener un conteo de polígonos eficiente sin sacrificar calidad visual. Además, se aplicaron técnicas de texturizado y mapeo UV para asegurar que los materiales respondieran correctamente a la iluminación del entorno (PBR).
